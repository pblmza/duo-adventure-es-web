# Duo Adventure (ES) — motor web

Motor no oficial para jugar en el navegador la versión en español del librojuego *Sword World 2.5 Duo Adventure*: lector de párrafos, pruebas con dados, panel del grupo y combate automatizado.

Este repositorio **no incluye el texto ni las ilustraciones del libro**. Al abrir la página se pide importar un paquete de contenido propio (`duo-adventure-contenido.json`), que se guarda solo en el navegador.

Sword World es una marca de Group SNE / Fujimi Shobo. Proyecto de fans, sin fines comerciales.
